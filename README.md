# VANTOR AUTO STUDIO — VELTOWEB Portfolio

Static HTML/CSS/Vanilla JS portfolio concept.

## Run
Open `index.html` directly or serve this folder with any static server. No npm or build step required.

## GitHub Pages
Upload the entire folder contents to a repository root (or project subfolder). All internal links and local assets use relative paths.

## Photo assets
The project uses editorial automotive photos from external image URLs for the online portfolio look, with local SVG fallbacks in `assets/images/` so layouts do not break if a remote image is unavailable. Replace the remote `src` values with your own locally hosted WebP/AVIF assets before commercial production.

## Demo disclaimer
This is a fictional portfolio concept. Reservation actions do not send data to a server.
